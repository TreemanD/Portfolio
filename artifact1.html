Artifact Definition

I created this course as part of my graduate studies in the Instructional Systems Technology program at Indiana University. The course artifact applies to my current job and provides an introduction on how to create a campaign audience using the new Audience Builder functionality in the Workday Learning LMS. I used Techsmith's Camtasia and Audiate applications to create this course. It was my first time using that software and serves as an example of how I can quickly learn and adapt to new course creation technologies.
